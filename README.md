# Speakeasy

Private, on-device dictation for Mac. Hold the Fn key, talk, and your words are typed where your cursor is.
Everything runs on your Mac; nothing you say leaves it.

This repository holds **downloads and the update feed only**. The app updates itself from here.

## Download

Get the latest `Speakeasy-x.y.z.zip` from [Releases](../../releases/latest), unzip it, and drag
**Speakeasy** into Applications.

**First launch:** macOS will say it can't verify the developer. Open **System Settings → Privacy &
Security** and click **Open Anyway**. Then allow Microphone and Accessibility when Speakeasy asks.

## Requirements

- A Mac with Apple silicon (M1 or newer), macOS 15 or later
- About 500 MB free for the speech model (downloaded once, on first run)
- For AI rewrites: macOS 26 with Apple Intelligence on, or Ollama / LM Studio installed

## Tip

Set **System Settings → Keyboard → "Press 🌐 key to" → Do Nothing** so the Fn key works for dictation.
